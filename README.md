# ТАйМСКВЕР — громче слов

Одностраничный музыкальный сайт, готовый для GitHub Pages.

## Публикация на GitHub Pages

1. Загрузите содержимое архива в корень репозитория.
2. В настройках репозитория откройте **Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.

Навигация использует hash-маршруты, поэтому страницы каталога корректно открываются и после обновления даже на адресе вида `username.github.io/repository/`.

Музыкальный плеер использует официальные промо-превью Apple Music. Полные записи не хранятся в проекте.
